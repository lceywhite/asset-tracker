# 行程模块 v2 设计迭代日志

这份日志面向产品经理和测试人员，记录每一轮原型改变了什么，以及用户会在哪些页面感知到变化。

## v2 原型第 1 版（2026-07-22）

状态：已被后续迭代重构；仅作第一版历史参考。

| 本轮变化               | 主要影响功能       | 主要影响界面       | 用户感知                                                       |
| ---------------------- | ------------------ | ------------------ | -------------------------------------------------------------- |
| 首页改为任务优先       | 行程浏览与继续处理 | 行程主页           | 首先看到今天需要准备或核对的行程，其次才是未来和历史行程       |
| 快速创建与逐步创建并存 | 新建行程           | 新建行程           | 熟练用户可在一页完成，新用户可按基本、时间、清单、确认逐步填写 |
| 携带清单按容器组织     | 行李准备           | 新建行程、行程详情 | 可从物品库或包箱批量加入，但不会改变物品档案的真实位置         |
| 临时清单项             | 非资产类随身物     | 新建行程、行程详情 | 车票、零食等不必先建立正式物品档案                             |
| 出发与返程双核对       | 防遗漏与防丢失     | 行程详情、全屏核对 | 出发前确认带齐，返程前再次确认需带回的物品                     |
| 三态核对结果           | 异常处理           | 全屏核对、核对结果 | 区分已确认、未找到和主动跳过，并可只复核未完成项               |
| 复制与模板入口         | 重复行程复用       | 行程主页、行程详情 | 周末出行和出差无需每次重新建立完整清单                         |

### 本轮主要待确认

1. 首页信息顺序与行程卡片密度。
2. 临时清单项是否保留，以及是否允许转为正式物品。
3. “未找到”和“跳过”是否保留为两个独立结果。
4. 返程核对的默认范围。
5. 模板入口最终放在行程主页还是“我的”。

## 设计确认记录（2026-08-06）

用户确认“以这版为准”，因此行程模块仍保持 v2，原型修订号固定为第 11 版。本记录不是第 12 版设计，没有新增界面或功能；后续变化进入工程实现日志，只有核心信息架构再次重构时才讨论行程模块 v3。

## 工程实现记录（2026-08-06，不增加原型版本）

第 11 版确认基线已经进入正式应用。主页、新建/编辑、携带清单、物品库、档案和核对不再是静态演示；用户可以在浏览器中真实创建并刷新保存。物品库按加号加入“本次添加”区，可在加入前同步打星；清单支持移动容器、全选/清除、标记双向切换、批量移动和二次确认移出；档案只显示当前阶段的一个核对动作，结果支持未找到、跳过、已确认和重新核对未完成项。设置页同步增加全局提醒规则。旧行程大弹层和旧列表/月历界面已经删除。

本轮是工程实现，不是产品结构变化，因此仍称“行程模块 v2 原型第 11 版”，App 版本也继续保持 `1.0.0-beta.1`，直到整个单人 MVP 形成新的可安装测试包再统一决定发布版本。
