## v3 确认点

- 当周日期轴只用小圆点标记“当天有行程”，不再挤入跨日标题条；
- 展开月历继续使用不同颜色的跨日标题条，完整表达周期和行程名称；
- 时间线卡片显示完整开始和结束时间，连接线使用分离的双色节点与虚线；
- 携带清单、物品库下钻和容器选择在当前档案上以连续弹窗完成；
- 现有移动容器可整包导入后代物品，新建容器只在用户选择后展开字段；
- 错加的容器可明确移除并二次确认，不影响真实容器与物品档案。
