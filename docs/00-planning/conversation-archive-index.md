## 记录规则

1. 保留用户与助手在界面中可见的原始消息及发生顺序。
2. 排除系统指令、开发者指令、环境注入、内部推理、工具调用和工具输出。
3. 对话原文用于追溯需求来源；实际实现以最后确认的模块说明、最终原型和工程接入计划为准。
4. 旧回复中的路径、状态和版本按当时原文保留，不代表当前有效状态。
5. 每次模块设计确认、工程接入完成或跨模块切换时更新本索引和对应续录。
