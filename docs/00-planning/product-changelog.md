# 产品迭代日志

## 单人 MVP 收口 M3 — Windows / Web 全应用验收（2026-08-07，已完成）

物品、空间、行程、核对、我的、社区入口和中央加号已经在 390×844 手机宽度与 1366×900 桌面网页逐项验收。桌面端使用居中的应用画布，避免卡片和表单无限拉宽；主要底部弹层也统一为适合桌面阅读的宽度。中央加号支持键盘 Enter 打开、Esc 关闭和焦点返回。八个正式路由均无页面级横向溢出、Vite 错误覆盖层或运行时错误。

## 单人 MVP 收口 M2 — 图片与备份安全（2026-08-07，已完成）

物品照片和空间头像现在会在本机保存前自动优化。物品档案最多保存 8 张图片，常见手机大图会压缩到最长边 1600 像素、单张约 1 MB 以内；空间头像使用更小目标。界面会显示处理进度和处理前后体积，本机容量不足时会给出明确提示，不会把失败误报成保存成功。

完整的破坏性恢复演练已经通过：先建立物品、空间、行程、携带关系和核对记录并导出备份，再经过两次确认清空全部数据，最后用备份替换恢复并抽查全部关联。损坏 JSON 和缺少物品表的备份都会被拦截。演练中发现并修复了“预检通过但备份对象被界面代理后无法写入 IndexedDB”的真实缺陷。详细证据见 [M2 图片与数据安全验收记录](../06-mvp-closure/m2-image-and-backup-verification.md)。
