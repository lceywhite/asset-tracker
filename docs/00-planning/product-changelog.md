# 产品迭代日志

## 行程模块 v2 — 数据模型与迁移第一阶段（2026-08-06，已完成）

行程 v2 的第一阶段已经进入正式工程，但用户界面还没有替换。旧行程会在打开数据库时自动升级：携带物品尽量关联到物品库和移动容器，无法安全判断容器的历史条目会保留为“待整理”而不是被删除；核对结果从简单的“是 / 否”升级为待核对、已确认、未找到和跳过。备份仍是 v3，因为没有增加新的数据表，同时新增保存星标提醒偏好。自动测试已覆盖旧数据库升级、创建与更新行程、阶段核对以及备份恢复。下一步主要影响行程主页、新建/编辑、携带清单、档案详情和核对界面。

## 单人 MVP — iOS 验收阶段调整（2026-08-06，已确认）

iOS 真机测试不再穿插于各功能模块开发中。当前先在 Windows 和网页端完成物品、行程、社区入口、我的与设置组成的单人 MVP，并完成全流程回归；整体功能完整后再集中迁移到 Mac，通过 Xcode 安装到 iPhone，验证长表单、相机、分享、触觉、离线冷启动和备份恢复。该调整不取消 iPhone 交付目标，只改变验收顺序。

## 行程模块 v2 — 设计确认与工程接入准备（2026-08-06，已确认）

行程模块 v2 原型第 11 版已经确认为正式工程接入基线。这里的“v2”表示行程模块第二代设计，“第 11 版”表示 v2 内部经历的第 11 轮原型调整；它们都不是 App 发布版本。当前 App 仍是 `1.0.0-beta.1`，物品模块 v3 已接入正式代码，行程正式页面仍是旧实现。下一阶段将先升级行程与核对数据模型、迁移和测试，再接入时间轴主页、统一建档、移动容器清单、购物车式选物、档案详情和阶段核对。

## 行程模块 v2 — 物品选择改为购物车式添加（2026-08-06，已纳入确认基线）

新建行程和行程详情中的物品入口统一改名为“添加物品”。携带物品清单将已有容器和物品放在前面，“添加移动容器”移动到页面末尾；顶部新增全选与清除，底部标记按钮支持再次点击清除所选星标。进入物品库后不再显示容易与批量管理混淆的勾选框，用户点击每件物品右侧“＋”加入本次待添加区，并可在页面下方集中查看或逐项移除，最后一次添加到目标容器。

## 行程模块 v2 — 携带物品清单二级流程（2026-08-06，已被第 11 版调整并确认）

携带物品清单已经从新建行程表单中拆成独立二级管理界面。用户必须先添加已有移动容器或新建容器，再在具体容器内从物品库选择物品；物品库同时支持搜索和按空间布局逐级下钻，并可多选加入。清单顶部会显示当前星标提醒规则及设置入口。单件物品保留勾选框和星标，移动端侧滑显示删除，拖拽可换到其他容器；勾选后底部只出现“标记、移动、删除”。所有删除都要二次确认，并且只会把物品移出本次行程，不会删除物品档案或改变实际位置。

## 行程模块 v2 — 星标并入物品管理（2026-08-06，已纳入确认基线）

独立的重点关注设置已取消，星标改为添加和管理物品时的直接操作。用户可以在单件物品上打星，也可以通过同一套选择状态批量标星、取消星标、移动或从行程清单移出；批量导入也集中到该管理界面。星标物品默认在出发和结束前一天晚上提醒，时间统一预留到“设置－偏好设置”调整，不再由每个行程单独配置。通用信息中的备注、时间线等仍是独立卡片，但阅读界面已移除卡片类型标签、编辑说明和类型预览。

## 行程模块 v2 — 通用信息卡片层级修正（2026-08-06，已纳入确认基线）

修正了把备注、时间线和新增入口嵌套进同一张外层卡片的错误。现在“通用信息”只作为大区域标题，备注以独立多行文本卡片呈现，工作日安排以独立时间线 / 分页卡片呈现，新增入口也是独立虚线卡片；三者同属一个区域，但卡片边界和类型清晰分开。

## 行程模块 v2 — 重点关注与通用信息收敛（2026-08-06，部分替代并纳入确认基线）

新建行程不再显示“行程中新增物品”，该入口改到档案建立后的物品清单中。重复和笼统的提前提醒规则暂时移除，替换为物品清单完成后的“重点关注”设置：用户可以单选、全选或批量选择物品，再切换为普通或重点关注；全部重点物品共用一组出发与返程 / 结束提醒时间，两类提醒均可关闭。页面同时隐藏了“必填”“单程 / 往返”“行程档案”等重复说明，并将备注、时间线及其他自定义卡片合并到同一个通用信息区域。

## 行程模块 v2 — 主页与档案信息卡片调整（2026-07-28，已纳入确认基线）

行程主页顶部改为与物品模块一致的搜索栏和新建加号，并恢复默认显示的当周七天日期轴，完整月历仍通过弱下箭头展开。新建页的提前提醒增加“不提醒”。行程档案不再单列“当前阶段”，物品核对进度和核对按钮合并在同一操作卡片内，并仅在完成核对后显示进度。自定义信息卡片增加键值、时间线 / 分页、清单和金额统计等预设格式；每日安排示例可按天翻页并查看当天时间线。独立旅行扩展视图暂时移除。

## 行程模块 v2 — 核心流程继续收敛（2026-07-28，已由后续版本细化并确认）

主页取消时间轴/日历抬头切换，改为点击日期标题后的弱下箭头展开月历；时间轴只显示行程卡片，不再把核对作为独立事件。新建页将时间简化为出发与返程，只按移动容器组织物品，并区分“从物品库添加”与“行程中新增并同步物品库”，核对设置暂时移除。详情页不再预先显示空的准备度；物品清单之后只出现一个与阶段匹配的核对按钮，完成核对后再展示结果。通用信息和自定义扩展卡片排在核对之后。

## 行程模块 v2 — 行动档案定位校正（2026-07-28，已纳入确认基线）

行程重新明确为“会涉及物品携带、检查或位置变化的行动”，覆盖通勤、普通外出、旅行、搬家和自定义类型。主页保留时间轴与日历；新建页统一为基本信息、行程信息、携带清单、核对设置和其他通用信息；详情页优先展示行程与物品。用户可在出发、途中、结束或任何需要的时候核对。旅行攻略、具体规划和花销只作为可选信息卡片，不占据核心流程。

## 行程模块 v2 — 完整旅行档案原型（2026-07-28，已否决）

这一版曾把时间轴原型扩展为攻略接入、每日路线、交通住宿和预订资料主导的完整旅行档案。随后确认该方向错误地把“行程”收窄为旅行规划，并让高级旅行功能喧宾夺主，因此不再作为实现依据，仅保留在历史参考目录中。

## 行程模块 v2 — 时间轴主题扩展（2026-07-28，已被第 4 版替代）

行程主页已选择“旅程时间轴”主题，并将同一套暖白、青绿色和日期时间轴语言扩展到新建行程、行程详情、模板选择、全屏核对和核对结果页面。新建页继续保留快速与逐步两种方式，详情页增加行程阶段轨道，模板页支持从常用模板和最近完成行程复用，核对流程继续区分已确认、未找到和跳过。本轮仍只更新设计原型和说明文档。

## 行程模块 v2 — 第一版交互原型（2026-07-22，已由第 11 版重构并确认）

行程模块开始按“计划—准备—出发核对—返程核对—复用”的完整闭环重新设计。主页优先呈现今天需要处理的行程，新建页同时提供快速与逐步两种方式，携带清单可以引用物品库和移动容器，但不会改变物品的真实位置。核对流程新增“已确认、未找到、跳过”三类结果，并设计了复制行程和模板入口。本轮仅增加交互原型和产品文档，尚未修改正式功能与数据。

这份日志面向产品、运营和测试人员，重点说明“用户看到什么变化、影响哪个功能和界面”，不要求理解代码。

## 物品模块 v3 — 第一轮使用体验修订（2026-07-16）

根据网页预览反馈，空间主页移除了重复的标题和“管理分区”按钮，分区管理继续保留在页面底部；物品视图增加按 ID、价值和加入时间排序。空间详情顶部现在显示完整路径，物品位置历史按最新优先排列，估值设置合并到财务信息，新增物品的币种与购入价输入也已拆分修复。
