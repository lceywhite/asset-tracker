# 产品迭代日志

这份日志面向产品、运营和测试人员，重点说明“用户看到什么变化、影响哪个功能和界面”，不要求理解代码。

## 物品模块 v3 — 第一轮使用体验修订（2026-07-16）

根据网页预览反馈，空间主页移除了重复的标题和“管理分区”按钮，分区管理继续保留在页面底部；物品视图增加按 ID、价值和加入时间排序。空间详情顶部现在显示完整路径，物品位置历史按最新优先排列，估值设置合并到财务信息，新增物品的币种与购入价输入也已拆分修复。

已确认的物品档案 v3 和物品主页 v3 已进入正式运行代码。Windows 网页端可以完整预览和操作，Mac/Xcode 与 iPhone 真机仍待下一步验收。

| 完整物品档案           | 查看、编辑、移动   | 物品档案           | 图片、弱 ID、财务、位置历史、备注和属性组更直观            |
| 分区式空间主页         | 收纳与浏览         | 物品主页           | 默认按我的包包、我的家、我的车库浏览，也能切换全部物品     |
| 通用空间详情与布局     | 房屋、车辆、容器   | 空间详情           | 可下钻、添加实际下级、移动物品、切换布局并拖动排序         |

## 物品模块 v3 — 后端第一阶段（2026-07-16，界面接入前）

物品档案和空间主页已经具备新的数据基础。当前应用界面暂时保持原样，目的是先保证旧物品、旧房间和旧包包能安全升级，再逐项替换为已确认的 v3 页面。

| 变动                | 主要影响功能     | 主要影响界面      | 用户感知                                         |
| ------------------- | ---------------- | ----------------- | ------------------------------------------------ |
| 物品档案数据扩展    | 新增、编辑、档案 | 后续物品档案 v3   | 可支持多图、备注、三类标准属性和自定义属性组     |
| 房间/包包统一为空间 | 收纳、定位       | 后续物品主页 v3   | 原有数据无需重新录入，可继续扩展区域和容器       |
| 三个默认分区落库    | 首页组织         | 后续分区管理      | 我的包包、我的家、我的车库可改名但不会误删       |
| 布局可以真实保存    | 空间排列         | 后续空间详情      | 多楼层和多套布局不再只是原型演示                 |
| 位置历史增强        | 移动、归位       | 后续档案位置历史  | 可记录从哪里移到哪里、原因、备注和时间           |
| 备份升级为 v3       | 数据安全         | 我的 → 数据与隐私 | 新空间数据进入备份，旧版备份仍可恢复             |
| 暂不自动折旧        | 财务、藏品价值   | 档案与空间价值    | 不会未经确认自动改变物品估值；当前只认可手动估值 |

详细技术范围见 `../03-item-module-v3/item-module-v3-backend-implementation.md`。

## 1.0.0-beta.1 — 单人 MVP / iPhone 测试版（2026-07-15）

本版本把可交互网页原型收敛为可安装的单人 App。Windows 侧已完成工程生成和自动化验证；最后一步需要在 Mac 上用 Xcode 选择签名并安装到 iPhone。

| 变动                     | 主要影响功能             | 主要影响界面                        | 用户感知                                            |
| ------------------------ | ------------------------ | ----------------------------------- | --------------------------------------------------- |
| 四个 Tab 与中央快捷添加  | 全局导航、物品、行程     | 底部“物品 / 行程 / + / 社区 / 我的” | 四个内容入口保持稳定，中央加号可直接添加物品或行程  |
| 设置与用户中心合并       | 个人资料、偏好、数据管理 | “我的”页                            | 在一个页面完成昵称、视图、备份、隐私和版本查看      |
| 社区入口恢复但不伪造内容 | 社区规划                 | “社区”页                            | 能看到未来方向，同时明确当前不会上传本地数据        |
| 行程与核对记录分离       | 出发核对、返程核对       | 行程详情与全屏核对                  | 每次核对独立保存，不会改坏原清单，可中途继续        |
| 备份升级为 v2            | 导出、恢复、清空         | “我的 → 数据与隐私”                 | 备份包含核对记录，并继续兼容 Release 0 备份         |
| 新增 iOS 原生容器        | 安装、离线、原生能力     | iPhone 主屏与系统分享面板           | 可经 Xcode 安装，备份可保存到“文件”，核对有触觉反馈 |
| 增加应用内版本记录       | 产品沟通                 | “我的 → 版本更新记录”               | 非研发人员也能直接了解版本变化                      |
