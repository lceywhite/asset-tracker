## 当前正式工程

### 已接入的物品模块 v3

- 物品主页默认空间视图，可切换全部物品；
- 我的包包、我的家、我的车库和自定义分区；
- 通用空间、区域、固定容器和移动容器；
- 物品档案 v3、多图、标签、位置历史、财务与属性组；
- 空间布局、递归藏品统计、空间核对；
- 旧房间/包包迁移、备份 v3 与自动化测试。

### 已接入的行程 v2 数据基础

- `Plan.modelVersion` 与 `CheckSession.modelVersion` 已升级为 2；
- IndexedDB 已升级为 v7，增加出发、返程、类型与核对种类索引；
- 旧日期、名称快照、包包引用和布尔核对结果会自动规范化，不会直接丢弃；
- 行程条目保存稳定 `itemId`、`containerId`、快照、星标和迁移待处理状态；
- 核对支持待核对、已确认、未找到和跳过四种状态；
- 备份仍为 v3，因为没有新增数据表；导出范围已包含行程提醒偏好；
- 数据迁移、服务写入、旧备份恢复和偏好备份自动测试已通过。

### 仍在运行的旧行程界面

- 正式路由仍为 `/plans`、`/plans/:id`；
- `TripsView.vue` 仍使用“列表 / 日历”抬头切换，不是已确认的周时间轴主页；
- `TripForm.vue` 仍是一个大型底部弹层，包含旧的重复类型、逐项提醒和“组合为新包”；
- 旧页面仍通过兼容字段读取 v2 数据，尚未使用移动容器清单和购物车式选物；
- 旧核对页仍以布尔交互呈现，尚未开放“未找到 / 跳过”操作；
- 详情页同时显示出发和返程核对，不是根据行程阶段只显示一个动作；
- 行程 v2 设计基线已经提交并建立草稿合并请求，后续代码继续追加到同一分支。
