## 当前正式工程

### 已接入的物品模块 v3

- 物品主页默认空间视图，可切换全部物品；
- 我的包包、我的家、我的车库和自定义分区；
- 通用空间、区域、固定容器和移动容器；
- 物品档案 v3、多图、标签、位置历史、财务与属性组；
- 空间布局、递归藏品统计、空间核对；
- 旧房间/包包迁移、备份 v3 与自动化测试。

### 仍在运行的旧行程模块

- 正式路由仍为 `/plans`、`/plans/:id`；
- `TripsView.vue` 仍使用“列表 / 日历”抬头切换，不是已确认的周时间轴主页；
- `TripForm.vue` 仍是一个大型底部弹层，包含旧的重复类型、逐项提醒和“组合为新包”；
- `Plan.modelVersion` 仍为 1，携带物品主要保存名称快照、分类、旧提醒类型和 `sourceBagId`；
- `CheckSession.modelVersion` 仍为 1，只记录布尔型“已确认 / 未确认”；
- 详情页同时显示出发和返程核对，不是根据行程阶段只显示一个动作；
- 行程 v2 原型和文档目前尚未形成 Git 提交。
