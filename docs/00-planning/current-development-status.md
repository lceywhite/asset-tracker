## 当前正式工程

### 已接入的物品模块 v3

- 物品主页默认空间视图，可切换全部物品；
- 我的包包、我的家、我的车库和自定义分区；
- 通用空间、区域、固定容器和移动容器；
- 物品档案 v3、多图、标签、位置历史、财务与属性组；
- 空间布局、递归藏品统计、空间核对；
- 旧房间/包包迁移、备份 v3 与自动化测试。

### 已接入的行程 v2 数据基础

- `Plan.modelVersion` 与 `CheckSession.modelVersion` 已升级为 2；
- IndexedDB 已升级为 v7，增加出发、返程、类型与核对种类索引；
- 旧日期、名称快照、包包引用和布尔核对结果会自动规范化，不会直接丢弃；
- 行程条目保存稳定 `itemId`、`containerId`、快照、星标和迁移待处理状态；
- 核对支持待核对、已确认、未找到和跳过四种状态；
- 备份仍为 v3，因为没有新增数据表；导出范围已包含行程提醒偏好；
- 数据迁移、服务写入、旧备份恢复和偏好备份自动测试已通过。

### 已接入的行程 v2 正式界面

- 主页使用搜索、当周七天日期轴、弱下拉月历和单一行程时间轴卡片；
- 新建和编辑统一为一份行动档案，包含类型、单双程、时间、地点、出行方式、携带摘要和备注；
- 携带清单必须按移动容器分组，可选择现有容器或新建并同步到物品空间；
- 物品库支持搜索和按空间下钻，点击加号进入“本次添加”区，可同步打星后一次加入；
- 清单支持单选/全选、星标双向切换、批量移动、二次确认移出、桌面拖动和移动端右滑；
- 详情根据行程阶段只显示出发、随时或结束核对中的一个入口；
- 核对支持待核对、已确认、未找到和跳过，可暂存、恢复并只重核未完成项；
- 设置页已接入统一的出发/结束星标提醒偏好，当前保存和展示规则，不虚构系统推送；
- 旧 `TripForm.vue` 和旧列表/月历、重复提醒、组合为新包流程已经从正式工程删除。
