# 单人 MVP 收口：项目进度审查与下一阶段计划

审查日期：2026-08-07

审查基线：`fbb573b feat: establish trip module v3 baseline`

## 1. 结论

当前项目已经完成单人 MVP 的核心业务骨架，不需要马上开启新的大型功能模块。物品模块 v3、行程模块 v3、四个核心 Tab、中央加号、“我的”、诚实的社区入口、IndexedDB 数据持久化、完整备份和 Capacitor iOS 工程均已存在。

下一阶段正式命名为“单人 MVP 收口与发布准备”。目标不是继续扩张功能，而是把现有产品整理成可以稳定交给 Mac/Xcode 和 iPhone 测试的候选版本。

## 3. 本次审查发现的问题

### P0：进入下一测试包前必须处理

1. **依赖安全**：2026-08-07 审计发现生产依赖 1 个中等级别问题（PostCSS）；完整依赖树共有 2 个高等级、2 个中等级问题，涉及 `brace-expansion`、`js-yaml`、`postcss` 和 `tar`。需要执行安全升级并重新跑构建、测试和烟雾回归。
2. **版本显示一致性**：Web/package 当前为 `1.0.0-beta.1`，Xcode 工程 `MARKETING_VERSION` 仍为 `1.0.0`。形成下一安装包时必须统一 App 展示版本和构建号。
3. **远端里程碑未完成**：行程 v3 当前提交只存在本地。必须完成 GitHub 登录、推送、远端 CI 和 PR/合并策略后，Mac 才能把它当作稳定共同来源。
4. **真机验收仍为空白**：Windows 的 `ios:sync` 成功只证明资源可以同步，不代表 Xcode 编译、Apple 签名或 iPhone 运行通过。

### P1：单人 MVP 收口范围

1. 为手机照片增加尺寸压缩、数量/体积提示和失败保护；先解决大图写入风险，再决定是否升级为 Blob 媒体仓储。
2. 使用真实测试数据完成“导出备份—清空—替换恢复—抽查关联”的破坏性演练，并验证损坏 JSON、缺表和旧备份的用户提示。
3. 清理仓库根目录已失效的 `fix_hv.cjs`、`fix_tf.cjs` 和旧 `preview.html`，保留有价值的历史说明到文档而不是可执行临时脚本。
4. 对“我的”、社区入口、全局快捷添加、错误提示、确认弹窗、键盘遮挡和窄屏文本做一次全应用一致性验收。
5. 把行程 v2 的内部兼容命名逐步改为中性名称，但不为纯命名修改升级数据库版本。

### P2：需要产品确认后再决定

1. 是否在单人 MVP 接入 iOS 本地通知；当前只有提醒偏好，没有真实系统通知。
2. 网页端是只保留本地开发/个人访问，还是部署公开 Web 入口。即使部署，数据仍是每个浏览器本地独立保存，不等于跨设备同步。
3. 估值折旧计算、真实社区、账号和云同步继续留在后续阶段，不阻塞当前 MVP。

## 4. 下一阶段执行顺序

### M1：发布工程清理

- 修复依赖审计问题并锁定兼容版本；
- 清理失效工程文件和过时内部命名；
- 统一 Web、应用内版本页与 Xcode 的版本/构建号；
- 保持 `npm run check`、`npm run smoke` 和 `npm run ios:sync` 全部通过。

退出条件：依赖审计无已知生产漏洞，仓库无临时脚本，所有版本显示可解释且一致。

执行结果（2026-08-07）：已完成。依赖树审计为 0 个已知漏洞；CI 官方 Action 升级到 v7；三个失效根目录文件已移除；旧 `ensureTripV2Data` 命名已改为 `ensureTripData`；App `1.0.0-beta.1` 与 Xcode `1.0.0 (1)` 的映射已集中管理并加入自动测试。`npm run check` 已通过，烟雾与 iOS 同步将在 M2/M3 完成后一并做最终回归。

### M2：图片与数据安全

- 实装照片压缩和写入失败提示；
- 补充大图、旧数据、损坏备份和当前 v8 备份恢复测试；
- 完成一次人工破坏性恢复演练并记录结果。

退出条件：常见手机照片不会轻易撑满本地存储；备份可在清空后恢复物品、空间、行程、核对和偏好关系。

### M3：单人 MVP 全应用验收

- 按用户任务逐项走查物品、空间、行程、核对、我的和社区入口；
- 检查 390×844、桌面网页、键盘、横向溢出、返回路径和危险操作确认；
- 决定本地通知和 Web 托管是否进入本次测试包。

退出条件：Windows/Web 没有 P0/P1 问题，并形成明确的测试包范围。

### M4：Mac/Xcode/iPhone 集中验收

- 从 GitHub 克隆已合并的稳定提交；
- `npm ci`、`npm run check`、`npm run ios:sync`；
- Xcode 完成 SPM、签名、编译和真机安装；
- 验收相机、分享、触觉、冷启动、离线使用、备份恢复和连续三天数据稳定性。

退出条件：真机无 P0/P1 数据问题，才决定下一 App 版本并形成可安装里程碑。

## 5. 明确不做

收口阶段不建设真实社区、云同步、多人共享、在线账号、地图追踪、AI 识图或交易能力。这些功能会改变后端、权限和隐私边界，必须另行立项。
