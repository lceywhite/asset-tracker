# M3 单人 MVP Windows / Web 验收记录

验收日期：2026-08-07  
适用版本：App `1.0.0-beta.1`、物品模块 v3、行程模块 v3

## 验收结论

Windows / Web 收口通过，未发现仍阻塞下一阶段的 P0 或 P1 问题。项目可以进入 M4 Mac/Xcode/iPhone 集中验收；这不等于 iOS 真机已经通过。

## 用户任务覆盖

- 物品：空间/物品视图切换、排序、快速/逐步添加、手机大图、档案、位置、移动、空间下钻和空间核对；
- 行程：周轴、下拉月历、跨日行程、建档、完整起止时间、信息卡片、移动容器整包导入、星标和阶段核对；
- 导航：物品、行程、社区、我的四个 Tab 与中央加号保持不变；
- 我的：资料、偏好设置、版本映射、数据占用、备份、清空和版本更新记录；
- 数据：旧 IndexedDB v4 升级到 v8、图片压缩、备份格式 v3 导出、清空、替换恢复、关联抽查和损坏文件提示；
- 社区：入口和产品边界说明真实可见，不虚构账号、内容或同步能力。

## 屏幕与交互矩阵

### 390×844 手机宽度

- 长表单、卡片、底部导航和中央加号无页面级横向溢出；
- 购入价的币种与金额可正常填写；
- 物品、空间、行程和核对完整闭环通过；
- 清空操作需要连续两次确认；从行程移除容器同样需要确认；
- 中央加号可以由键盘 Enter 打开，Esc 关闭后焦点返回原按钮。

### 1366×900 桌面网页

- 应用内容限制在居中的 1180px 画布内，不再把移动端卡片无限拉宽；
- 物品主页、空间详情、物品档案、行程主页、行程档案、社区、我的和版本更新八个正式路由逐页加载完成；
- 所有路由均无 Vite 错误覆盖层、运行时错误或页面级横向溢出；
- 主要底部弹层在桌面限制为 672px 左右的可读宽度，手机仍保持全宽。

## 明确不进入本次测试包

- 系统级本地通知：偏好设置仍只保存规则；必须在 M4 真机阶段验证权限、时区、重复提醒和取消逻辑后再决定接入；
- 公开 Web 托管：当前 Windows/Mac 均可本地运行网页预览，但没有部署到公网，也没有跨浏览器或跨设备同步；
- 真实社区、账号、云同步、估值折旧和在线攻略继续留在后续阶段。
