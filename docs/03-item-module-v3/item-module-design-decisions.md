# 物品模块设计决策与待办

更新日期：2026-07-15  
状态：物品档案 v3 决策记录，最终总说明见 `item-module-v3-design-spec.md`

版本标记：本文件所记录的添加物品、物品档案与完整编辑方案正式定义为“物品模块 v3”，并作为后续物品主页设计基线。

## 已确认体验规则

- 添加物品默认进入快速添加，页面内可以切换为逐步添加。
- “设置 → 偏好设置”后续增加默认添加方式：快速添加 / 逐步添加。
- 物品 ID 由系统自动生成，是唯一只读标识，用户不可修改。
- 分类用于选择物品的属性类别，例如电子设备、衣服、工具、箱包；标签是用户自定义气泡，两者分开编辑。
- 物品档案首屏弱化显示 ID；位置历史紧跟当前位置并默认折叠；自由信息统一命名为“备注”。
- 产品属性、财务信息、维护属性默认折叠，只展示已经填写的信息。
- 完整编辑页展示全部标准字段和档案完整度；每个属性组的信息项可以新增或删除。
- 自定义属性组可以改标题、删除、新增多个属性组，并在组内新增或删除信息项。

## 已确认估值偏好

“设置 → 偏好设置”后续增加默认估值方式：

1. 不计算；
2. 手动估值；
3. 按使用年限直线折旧。

默认选择“不计算”。没有有效财务数据或未选择估值方式时，物品档案不显示当前估值。

## 暂缓待办：财务统计阶段再完善

- 不同分类的默认使用年限和残值率；
- 直线折旧起算日、暂停、改价和舍入规则；
- 手动估值覆盖自动估值的优先级和历史记录；
- 总购入价、当前总估值、分类资产分布和折旧趋势；
- 财务信息的隐私开关、导出范围和社区可见性；
- 发票、保修、保险和维护成本的统计口径；
- 缺失价格、币种、多数量物品和组合物品的计算方式。

上述财务功能当前只记录设计与待办，不修改业务代码或数据库。
