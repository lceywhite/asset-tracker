# 物品模块 v3 设计迭代日志

这份日志面向产品经理、设计评审和测试人员，说明每一轮为什么变化、用户会看到什么，以及影响哪些界面。

## v3 界面细节修订 — 信息减负与录入修复（2026-07-16）

| 变动                 | 主要影响      | 用户感知                                                         |
| -------------------- | ------------- | ---------------------------------------------------------------- |
| 移除空间主页重复抬头 | 空间视图      | 进入页面后直接看到分区，分区管理仍从底部“新增分区”或双击标题进入 |
| 增加物品排序         | 物品视图      | 可按物品 ID、价值、加入时间排列，选择会保存在本机                |
| 标明当前空间路径     | 空间详情      | 顶部显示“分区 / 上级空间 / 当前空间”，下钻后不易迷路             |
| 位置历史倒序         | 物品档案      | 最新一次位置变化固定显示在最上方                                 |
| 估值归入财务信息     | 完整档案编辑  | 估值不再单独占一个属性大类，与购入价、购买时间等信息集中维护     |
| 修复购入价控件       | 快速/逐步添加 | 币种和金额改为两个清楚的输入区域，金额支持小数键盘和 `0.00` 提示 |

## v3 后端第一阶段 — 数据模型与兼容迁移（2026-07-16）

| 变动               | 主要影响                         | 用户感知                                               |
| ------------------ | -------------------------------- | ------------------------------------------------------ |
| 物品档案升级为 v3  | 物品新增、编辑、详情的数据基础   | 当前界面暂未整体变化，后续可承载多图、属性组和完整档案 |

| 估值保持克制       | 档案财务摘要、空间藏品价值       | 只接受手动估值，暂不产生未经确认的折旧结果             |

本阶段为后端基础建设，正式 v3 页面将在下一阶段逐项接入。

## v3 候选 3 — 空间价值与通用详情（2026-07-15）

- 包包不再直接进入核对，改为与房屋、车辆一样先进入空间详情。
- 每一级空间增加头像、空间价值与藏品价值。
- 空间卡片开始预览直接下级空间。
- 空间详情确立“基本信息、布局、直属物品清单、核对”的统一骨架。

主要影响：物品主页、包包详情、房屋详情、车辆详情。

## v3 候选 2 — 分区与空间树（2026-07-15）

- 放弃“所有顶级空间平铺”的首页方案。
- 明确分区是首页展示层，不属于实际位置层级。
- “我的包包”可直接从移动容器开始；“我的家”和车辆类分区从大型空间开始。
- 房屋详情采用近似户型图的区域布局。
- 固定容器与移动容器层级相同，但使用目的不同。

主要影响：物品主页的信息架构、空间/区域/容器关系。

## v3 候选 1 — 初版物品主页（2026-07-15）

- 提出空间视图与全部物品视图。
- 尝试以“我的家、办公室、移动空间”作为平级空间卡片。
- 加入区域、容器、未归位和无位置等入口。

评审结论：与用户希望的“按使用场景分区、不同分区从不同层级开始”不一致，因此不作为定稿基线。

## v3 定稿 — 物品档案（2026-07-15）

| 变动                 | 主要影响         | 用户感知                                       |
| -------------------- | ---------------- | ---------------------------------------------- |
| 快速/逐步双添加方式  | 添加物品         | 默认一页快速录入，也能切换流程式引导           |
| 删除无效状态标识     | 添加物品         | 名称下不再显示“在用、私人”                     |

| 分类与标签分离       | 添加、编辑、档案 | 分类用于标准归类，标签用于个性化标记           |
| 重排档案首屏         | 物品档案         | 名称和信息在左、图片在右，当前位置和历史更直观 |
| “自由信息”改为“备注” | 档案、编辑       | 命名更符合成熟应用习惯                         |
| 属性组可增删         | 完整编辑         | 标准信息项和自定义属性组都能按需要调整         |
| 估值规则进入偏好待办 | 设置、财务       | 暂不强制计算，没有有效数据时不显示估值         |

## 更早的产品约束（本次设计持续继承）

- 单人 MVP 以 Xcode 安装到 iPhone 为阶段性交付标准。
- Windows 端需要持续支持网页预览和调试。
- 保持物品、行程、社区、我的四个核心 Tab 和中央快捷加号。
- 设置与用户中心合并，社区保留入口。
- 先完成界面设计确认，再调整工程和数据结构。
