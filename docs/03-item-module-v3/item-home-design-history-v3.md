# 物品主页设计 v3

更新日期：2026-07-15  
状态：历史迭代记录，最终定稿已汇总至 `item-module-v3-design-spec.md`

归档说明：本文件保留主页从提案到定稿的过程。工程实现应以 `prototypes/item-home-v3.html` 和 `item-module-v3-design-spec.md` 为准。

## 已确认版本标记

- 添加物品、物品档案和完整编辑原型正式标记为“物品模块 v3”。
- v3 是后续物品主页、空间、容器和列表视图的统一设计基线。

## 已确认的主页结构方向

- 物品主页默认按“空间”浏览，同时保留“物品”视图入口。
- 分区是主页的信息组织层，不属于物品的实际位置层级；不同分区可以从不同层级开始展示。
- 实际位置层级为：空间（L0）→ 区域（L1）→ 容器（L2）→ 物品。
- 空间用于表示独立地点或使用环境，例如我的家、办公室、移动空间。
- 区域用于表示空间内的位置，例如书房、卧室、玄关。
- 容器分为固定容器和移动容器。固定容器用于收纳定位；移动容器用于携带、搬家打包、防丢和反复核对。
- 大型物品可以直接放在空间或区域下，不强制进入容器。
- “我的包包”分区可以直接从移动容器（L2）开始，不强制建立空间与区域。
- “我的家”分区从房屋空间（L0）开始，进入后通过近似户型图的布局查看区域（L1）。
- “载具”分区从车辆空间（L0）开始，可继续进入后备箱等区域（L1）及露营箱等移动容器（L2）。

## 页面与入口

- 主页：搜索、空间/全部物品切换、空间概览、待整理入口。
- 空间详情：区域、常用容器、空间直属物品、整理模式。
- 容器详情：位置路径、子容器、直接存放物品、放入物品与核对入口。
- 全部物品：分类/标签/位置筛选、排序、列表/网格切换、多选入口。
- 底部中央加号保持存在，提供快速添加物品、新建空间或区域、新建容器。

## 与 v3 物品档案的一致性

- 列表只展示扫描决策需要的信息：图片、名称、分类/标签、完整位置路径和有效估值。
- 没有财务信息时不显示估值占位数字。
- 点击物品后进入 v3 物品档案；新增物品默认进入 v3 快速添加。

本文件仅记录界面与信息架构，不修改业务代码、数据库或估值逻辑。

## 空间卡片与详情补充规则

- 包包和其他移动容器与普通空间使用相同的详情页，不再点击后直接进入核对界面；核对作为详情页“物品清单”的操作入口。
- 每一级空间都可以上传图片作为头像。
- 空间卡片右侧弱化展示“空间价值”和“藏品价值”；空间价值由用户在新建或编辑空间时填写，藏品价值为内部收纳物品价值汇总。
- 空间卡片预览最多几个直接下级空间，用户可以点击预览直接下钻；没有下级空间时展示直属物品数量并进入该空间详情。
- 默认预设三个可改名分区：我的包包、我的家、我的车库；新增分区与新增空间继续沿用原版本逻辑。
- 所有层级的空间详情统一为：基本信息、添加子空间、添加物品、布局、直属物品清单和核对入口。
- 布局支持多套方案或楼层，通过左右按钮切换；编辑布局时可以新增布局并改变子空间排列。
- 物品清单只显示直属于当前空间层级的物品；点击物品进入 v3 物品档案。

## 空间界面第二轮调整

- 分区标题不单独提供“改名”按钮；桌面端可双击标题进入编辑，所有平台都可以从分区管理界面修改。
- 用户界面不显示 L0、L1、L2 等内部层级标识，改为显示实际下级名称和数量，例如“5 个区域”。
- 空间卡片本身就是进入空间详情的入口，不再显示“进入空间详情”或“查看完整布局”文字按钮。
- 有下级空间时预览下级空间；没有下级空间时直接预览内部物品。
- 空间详情不显示空间价值，仅显示藏品价值、下级空间数量和物品数量。
- 添加按钮使用真实下级名称，例如房屋显示“添加区域”，区域显示“添加容器”。
- 布局标题后仅在存在多个布局时显示右箭头；进入编辑状态后显示新增布局按钮。
- 布局编辑允许拖动下级空间调整排列。
- 分区管理提供排序、编辑名称与说明、新增分区；三个默认分区不可删除，自定义分区可以删除。
