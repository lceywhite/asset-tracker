# 物品模块 v3 设计总说明

更新日期：2026-07-16  
状态：设计阶段定稿，等待确认后进入工程实现  
适用端：iPhone App、桌面与移动网页  
关联原型：`prototypes/item-profile-v3.html`、`prototypes/item-home-v3.html`

## 1. 产品目标

物品模块帮助单人用户完成四件事：快速建立物品档案、知道物品在哪里、理解空间内如何收纳、在出门或搬运时核对容易遗漏的物品。

v3 不把物品库设计成单纯表格，而是把“物品档案”和“空间树”作为两个互相连接的核心视图：

- 物品档案回答“这是什么、值多少钱、有什么属性、现在在哪里”。
- 物品主页回答“我的物品如何分布、这个空间里有什么、下一层如何排列”。

## 2. 全局约束

- 保持“物品、行程、社区、我的”四个核心 Tab。
- 保持底部中央快捷加号，可快速添加物品或进入其他新增入口。
- 设计先确认，再调整前端、数据模型与后端逻辑。
- 阶段性交付标准仍是可通过 Xcode 安装到 iPhone 的单人 MVP。
- Windows 开发阶段保留网页预览和调试能力，最终 iPhone 与网页均能进入应用。
- 社区入口保留，但单人阶段不上传或公开本地物品数据。

## 3. 物品档案原型 v3

### 3.1 添加方式

- 默认进入“快速添加”，熟练用户在一页完成录入。
- 页面提供“切换为逐步添加”。
- 逐步添加采用流程式引导，适合首次使用或信息较多的物品。
- 后续在“我的 → 偏好设置”增加默认添加方式：快速添加 / 逐步添加。
- 添加页不显示没有实际作用的“在用”“私人”标识。

### 3.2 基础字段

- 物品 ID：系统自动生成的唯一标识，只读且不可修改。
- 名称：主要识别信息。
- 分类：标准物品属性类别，例如电子设备、衣服、工具、箱包。
- 标签：用户自定义气泡，与分类分开管理。
- 图片：档案视觉识别入口。
- 当前位置：连接空间树中的具体空间或容器。
- 备注：原“自由信息”的统一名称。

### 3.3 档案详情

- 顶部以名称为主，ID 弱化显示。
- 图片位于右上区域，基础信息在左侧平行展示。
- 财务摘要按“当前估值、购入价、购入时间”呈现；没有有效数据时不显示当前估值。
- 当前位置之后紧跟位置历史，位置历史默认折叠。
- 产品属性、财务信息、维护属性默认折叠，只显示已经填写的信息。
- 自定义属性组与标准属性组采用一致的阅读方式。

### 3.4 完整编辑

- 只在完整编辑界面展示档案完整度。
- 标准属性组内的信息项可以新增或删除。
- 自定义属性组可以新增多个、修改标题、删除整个组，并在组内新增或删除信息项。
- 备注保留在完整编辑界面。

### 3.5 估值偏好

后续在偏好设置中提供：

1. 不计算；
2. 手动估值；
3. 按使用年限直线折旧。

默认“不计算”。完整折旧规则、财务统计、历史估值、残值率、维护成本与隐私范围留到财务功能阶段处理，本阶段不实现。

## 4. 物品主页原型 v3

### 4.1 首页结构

顶部为搜索框与“空间 / 物品”视图切换，默认进入空间视图。

主页以“分区”为展示骨架。分区只是首页组织方式，不是实际位置层级。默认预设三个可改名分区：

- 我的包包：直接展示随身、旅行、搬家使用的移动容器。
- 我的家：展示房屋等大型固定空间。
- 我的车库：展示车辆以及车内收纳空间。

用户可以新增自定义分区。默认分区可改名但不可删除，自定义分区可删除。

### 4.2 实际空间关系

内部数据仍需区分以下关系，但用户界面不显示 L0、L1、L2 编号：

- 空间：房屋、车辆等最高层实体。
- 区域：玄关、卧室、书房、乘员舱、后备箱等。
- 容器：衣柜、抽屉、防潮柜、背包、行李箱、露营箱等。
- 物品：可以放在任意层级；大型物品不强制进入容器。

固定容器用于日常收纳定位；移动容器用于随身携带、旅行、搬家、防丢和反复核对。

### 4.3 空间卡片

- 每一级空间可以上传图片作为头像。
- 卡片标题下展示自然语言数量，例如“5 个区域 · 96 件物品”，不显示内部层级编号。
- 卡片右侧弱化展示空间价值与藏品价值。
- 空间价值由用户在新建或编辑空间时填写，例如房屋总价或车辆价值。
- 藏品价值为该空间内部物品有效估值的汇总。
- 有下级空间时，卡片预览几个直接下级空间；点击预览可直接下钻到目标空间。
- 没有下级空间时，卡片直接预览内部物品。
- 点击卡片主体默认进入当前空间详情，不设置“进入详情”或“查看完整布局”文字按钮。

### 4.4 空间详情

所有层级共用同一套详情结构：

1. 基本信息：头像、标题、下级空间数量、物品数量、藏品价值。
2. 操作：添加实际的下级空间、添加物品。例如房屋显示“添加区域”，区域显示“添加容器”。
3. 布局：展示直接下级空间的排列。
4. 物品清单：只展示直属于当前层级的物品。
5. 核对：位于物品清单标题右侧，进入当前空间的核对模式。

空间详情不显示空间价值，避免与藏品价值争夺注意力。点击物品进入物品档案 v3。

### 4.5 布局

- 布局用于直观表达下级空间之间的位置关系。
- 多楼层或多套布局时，在布局标题后显示右箭头进行切换；只有一个布局时不显示箭头。
- 点击“编辑”进入布局编辑状态。
- 编辑状态在布局标题后显示“＋”，可以新增布局。
- 下级空间支持拖动排列。
- 布局表达的是帮助记忆的位置关系，不要求成为精确建筑 CAD 图。

### 4.6 分区管理

- 首页不提供单独的“改名”按钮。
- 桌面网页可以双击分区标题进入编辑；所有端都可以从“管理”进入分区管理。
- 管理界面支持拖动排序、修改名称与说明、新增分区。
- 三个默认分区不可删除；自定义分区可以删除。

## 5. 两个原型的连接关系

```text
物品主页
  ├─ 点击空间卡片 → 空间详情
  ├─ 点击下级空间预览 → 目标空间详情
  ├─ 点击直属物品 → 物品档案
  └─ 中央加号 / 添加物品 → 快速添加（默认）

物品档案
  ├─ 点击当前位置 → 对应空间详情
  ├─ 编辑 → 完整编辑
  └─ 查看位置历史 → 历次空间变化
```

## 6. 后续工程影响（本阶段未实施）

正式实现前需要重新评估当前 room、bag、space、section 数据结构，避免继续以固定页面类型承载层级关系。建议后续工程设计能够表达：

- 分区及其排序、名称和默认/自定义状态；
- 通用空间节点、父子关系、空间类型和固定/移动属性；
- 空间头像、空间价值、布局及布局内坐标；
- 物品直属空间关系与位置历史；
- 藏品价值递归汇总；
- 核对会话与空间直属/递归物品范围。

这些只是进入工程前的设计约束，不代表已经修改数据库或服务代码。

## 7. 暂缓事项

- 完整财务统计和折旧规则；
- 多币种及无价格物品汇总口径；
- 布局编辑的精确手势、缩放和无障碍替代方式；
- 移动容器跨空间移动时的位置历史与批量移动确认；
- 社区中空间布局和物品档案的公开范围；
- 跨设备同步、账号体系与冲突处理。
