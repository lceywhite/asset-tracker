# 物品模块 v3 后端实现记录

更新日期：2026-07-16
状态：后端与网页界面接入完成，等待 Mac/iPhone 验证

## 本阶段目标

在不破坏现有单人 MVP 页面和旧数据的前提下，为已确认的物品档案 v3、物品主页 v3 建立可持续使用的数据模型和业务接口。

第一阶段完成数据层、服务层、迁移、备份与自动化测试；第二阶段已经将物品添加、档案详情、空间主页和空间详情接入正式运行界面。

## 界面接入结果

- 物品主页默认空间视图，可切换全部物品，搜索同时覆盖物品、空间和标签；
- 默认三个分区及自定义分区接入真实数据，支持管理、改名、说明、排序和删除规则；
- 空间卡片展示头像、自然语言数量、空间价值、藏品价值、下级空间或直属物品预览；
- 所有空间层级统一进入空间详情，支持新增下级空间、添加/移入物品、布局切换和编辑；
- 空间核对覆盖当前空间及全部下级空间，可保存进行中与已完成记录；
- 新增物品默认快速添加，可切换四步逐步添加；
- 完整档案编辑支持多图、只读 ID、分类/标签、位置、估值、标准字段增删和多个自定义组；
- 物品档案按照已确认原型展示财务摘要、当前位置、折叠历史、备注及只含已填写信息的折叠属性组；
- “我的”偏好设置增加默认主页视图、默认添加方式和估值规则。

## 数据库升级

数据库由 v5 升级到 v6，新增：

| 数据表         | 用途                                                   |
| -------------- | ------------------------------------------------------ |
| `homeSections` | 我的包包、我的家、我的车库及自定义首页分区             |
| `spaceNodes`   | 通用空间节点，可表达房屋、车辆、区域、固定/移动容器    |
| `spaceLayouts` | 一个空间的多套布局及直接下级空间的位置、尺寸和排列顺序 |

旧 `rooms`、`bags` 暂时保留供现有页面使用。升级时会为它们生成对应的通用空间节点：

- 旧房间 → 默认住所下的区域；
- 旧包包 → 我的包包分区下的移动容器；
- 旧物品的 `roomId` → 常驻位置；
- 旧物品的 `bagId` 优先作为当前位置，没有包包时使用房间。

迁移保留原物品 `id`，不会因为升级重新生成身份。

## 物品档案 v3 模型

主要新增或明确：

- `itemCode`：用户界面弱显示的短编号；内部唯一主键仍为不可修改的 `id`；
- `modelVersion: 3`：标记物品已采用 v3 档案结构；
- `images`：支持多张图片和封面图，继续提供旧 `photo` 字段兼容当前页面；
- `locationNodeId`：当前位置；
- `homeLocationNodeId`：常驻/归位位置；
- `purchasePrice`、`currency`、`purchaseDate`、`purchaseChannel`：财务摘要字段；
- `valuation`：保存不计算、手动估值、直线折旧三种模式所需数据；
- `propertyGroups`：产品属性、财务信息、维护属性和任意多个自定义属性组；
- `notes`：统一使用“备注”名称。

三个标准属性组可删除其中的信息项；自定义组可改标题、删除、新增多个。阅读界面可以通过已填写字段筛选接口只展示有内容的信息。

## 估值边界

本阶段遵守已确认的暂缓决策：

- 默认不计算估值；
- 手动估值可以作为有效藏品价值；
- 直线折旧仅保存模式和预留字段，不执行计算；
- 空间藏品价值只汇总有效手动估值；
- 分类使用年限、残值率、折旧历史与财务统计继续留到财务阶段。

## 空间与布局能力

服务层已经支持：

- 默认三个分区不可删除但可以改名、改说明和排序；
- 创建自定义分区并在空分区时删除；
- 任意深度的父子空间节点；
- 空间、区域、固定容器、移动容器；
- 空间头像、多图片、空间价值和币种；
- 防止把空间移动到自身或自己的下级；
- 获取面包屑路径、直接下级和建议的“添加区域/容器/子容器”文案；
- 递归统计藏品数与有效藏品价值；
- 多套布局、布局排序和直接下级空间摆放；
- 删除或移动空间时清理失效布局引用。

## 物品位置能力

- 新建物品时可以同时保存当前位置与常驻位置；
- 移动物品会在同一数据库事务中更新物品和新增位置历史，避免只成功一半；
- 历史记录包含来源、目标、原因、备注和时间；
- 删除物品时同步删除该物品的位置历史；
- 删除包含物品或下级空间的节点默认拒绝，显式级联时会解除物品的位置引用。

## 备份兼容

备份格式由 v2 升级到 v3，包含新增的三个数据表。恢复继续兼容：

- v1：没有独立核对记录和 v3 空间表；
- v2：有核对记录但没有 v3 空间表；
- v3：完整保存物品模型 v3 和空间树。

恢复旧备份后会自动补齐默认分区、通用空间节点和物品 v3 字段。
